# بنك مزاولة المهنة

موقع ثابت (بلا خادم) لمراجعة أسئلة مزاولة المهنة (مساعد طبيب، تمريض، قبالة، أسنان) واختبارات محوسبة بمؤقّت (نماذج جاهزة، مخصّص، حسب الموضوع، مع قسم مقالي اختياري بتصحيح ذاتي).

## التشغيل المحلي
```bash
npm ci
python3 -m http.server 8000 --directory site   # ثم افتح http://localhost:8000
```

## الفحوص
| الأمر | ما يفحصه |
|---|---|
| `npm run lint` | ESLint، ويمنع `innerHTML` وما شابهه. ويفرض سقف الصياغة: ES2019 لكل `site/js` (فأي `??` أو `?.` أو `import()` يفشل الفحص بدل أن يعطّل الموقع في متصفح قديم دون أن يراه أحد)، وES5 لـ `site/js/guard.js` |
| `npm test` | اختبارات الوحدة: منطق الاختبار، التخزين، سلامة بيانات البنك، وعدم استعمال `globalThis` بلا حارس أو ميزات تعابير نمطية أحدث من السقف (`tests/compat.test.mjs`) |
| `npm run scan` | فحص أمني: واجهات خطرة، أسرار، سياسة CSP بقائمة سماح (`'self'` و`'none'` فقط، و`data:` للصور)، وجود noindex، موارد خارجية في وسوم HTML وفي CSS، روابط غير https، ملفات مصدر في مجلد النشر. الطلبات الصادرة من JS لا يفحصها نمط نصي: تمنعها CSP (`connect-src 'self'`) ويرصدها اختبار e2e |
| `npm run test:e2e` | متصفح فعلي: جوال/لوحي/مكتب، المراجعة، الاختبار، المؤقّت، عبث التخزين، ورسالة البدء حين يعجز المتصفح عن تشغيل الموقع |
| `npm run check` | lint + test + scan |

متغير `CHROME_PATH` يحدّد مسار المتصفح لاختبار e2e. و`E2E_SLOW_HASH_MS=250` (اختياري) يؤخّر رسم كل انتقال في الموقع عمدًا ليكشف سباقات التوقيت في الاختبارات؛ يشغّله `ci.yml` تمريرةً ثانية لاختبار الموقع (`tests/e2e/smoke.mjs`) فقط، فصفحة الطبيب لا تعتمد على الانتقال بين المسارات. و`E2E_OLD_BROWSER=1` (اختياري) يحذف من المتصفح قبل بدء الموقع الواجهات الأحدث من سقف الموقع (`Array.flat` و`replaceChildren` و`Object.fromEntries` وغيرها، القائمة في `tests/e2e/old-browser.mjs`) فيُثبت أن الموقع يعمل بدونها؛ يشغّله `ci.yml` تمريرةً ثالثة، وأي استعمال لها يُفشل الاختبار (جُرّب بإعادة `.flat()` عمدًا ففشل).

## النشر
الخطوات الكاملة (إنشاء المستودع، الرفع، تفعيل Pages، حماية الفرع، التراجع): [docs/DEPLOY.md](docs/DEPLOY.md).

عند الدمج في `main` يعمل `.github/workflows/deploy.yml`: يعيد الفحوص ثم ينشر مجلد `site/` على GitHub Pages.
فعّل من إعدادات المستودع: **Settings → Pages → Source: GitHub Actions** (مرة واحدة).
ولا دمج قبل نجاح `CI` على الـ PR (فعّل حماية الفرع: Require status checks).

## بنية المشروع
```
site/            الموقع المنشور (index.html، css، js/ بوحدات ES، data/، fonts/ خطوط مستضافة ذاتيًا بترخيص OFL)
  js/logic.js        منطق نقي مختبَر (اختيار الأسئلة، الدرجة، المؤقّت، الفلاتر)
  js/exam-state.js   حالة جلسة الاختبار والتحقق من المخزَّن (غير موثوق)
  js/store.js        غلاف localStorage آمن مع رجوع للذاكرة
  js/dom.js          بناء DOM بعقد نصية فقط
  js/guard.js        سكربت كلاسيكي (ES5) يعمل قبل التطبيق: رسالة عربية ظاهرة + زر إعادة تحميل إن لم يشتغل التطبيق بدل «جارٍ تحميل البنك…» الأبدية
  js/plan.js         النماذج والمخصّص والمدد والتنبيهات؛ js/topics.js، js/essay.js: المواضيع والمقالي (بيانات اختيارية)
  js/views/          home، review، setup، instructions، exam، essay-exam، results
netlify.toml     إعداد اختياري لاستضافة ثانية على Netlify (publish=site، بلا بناء)
data/            خط البيانات (التفريغ، الدمج، التحقق، التقارير)
tools/           build.py (دفعة 1) → merge_batch2.py (دفعة 2) → finalize.py (نتيجة نهائية → site/data/bank.json)
tests/           وحدة + e2e
```

## المتصفحات القديمة: ما تضمنه الشيفرة وما لا تضمنه
**ما تضمنه (ومُختبَر آليًا):**
- **الصياغة**: ES2019، يفرضها ESLint ويؤكدها es-check المستقل. الحد الأدنى النظري Chrome 66 وFirefox 60 وSafari 11.1 (الأدنى بين دعم الوحدات ودعم `catch` بلا متغير). ESLint بسقف 2019 لا يمنع ميزات التعابير النمطية من ES2018 (lookbehind: Safari 16.4، المجموعات المسمّاة، `\p{…}`) فيمنعها اختبار وحدة (`tests/compat.test.mjs`)، ولا يستعملها الموقع اليوم.
- **الواجهات**: لا يستعمل الموقع `replaceChildren` ولا `.flat()` ولا `globalThis` (إلا حيث لا يوجد `window`). وفي تمريرة e2e يُحذف من المتصفح قبل البدء 15 واجهة أحدث من سقف الموقع (القائمة في `tests/e2e/old-browser.mjs`) ويجب أن يمرّ كل شيء بدونها.
- **متصفح لا يشغّل الموقع**: بدل «جارٍ تحميل البنك…» الأبدية يظهر نص عربي وزر «إعادة تحميل الصفحة» (`site/js/guard.js`) عند: عدم دعم الوحدات، أو تعذّر تحميل أحد سكربتات الموقع، أو خطأ صياغة أو تشغيل في ملفاته، أو رفض غير ملتقط مصدره ملفاته، وذلك قبل أن يرسم التطبيق شاشته الأولى. تُحتسب أخطاء ملفات **الموقع نفسه** فقط (نفس الأصل): ضجيج السكربتات التي تحقنها متصفحات داخل التطبيقات أو الإضافات لا يُظهر الرسالة. كشف الرفض غير الملتقط يحتاج `unhandledrejection` (Chrome 49 وFirefox 69 وSafari 11)، فعلى Firefox 60–68 يبقى هذا النوع وحده بلا رسالة.

**ما لا تضمنه:**
- **تعليق التحميل**: إن أبطأت الشبكة أو توقفت وسط التنزيل (ملف البنك أو ملفا المواضيع/المقالي اللذان ينتظرهما الإقلاع) بقي «جارٍ تحميل البنك…» بلا رسالة ولا مهلة. عمدًا: لا مؤقّت، لأن «جارٍ التحميل» على شبكة بطيئة حالة صحيحة وليست فشلًا؛ اقتراح مهلة وتلميح «تحقق من اتصالك» بانتظار قرارك (انظر DECISIONS.md).
- **CSS على متصفحات أقدم من 2021**: قاعدتا `.wrap` و`.top` تأخذان هوامش الجانبين من `padding-inline` (Chrome 87 / Safari 14.1) و`clamp()` داخل `padding` (79 / 13.1)، فعلى Chrome 66–86 وSafari حتى 14.0 يلتصق المحتوى بحافتي الشاشة؛ و`gap` في flex (84 / 14.1) تضيع به المسافات بين عناصر كثيرة؛ و`:focus-visible` (86 / 15.4) فتسقط أنماط التركيز المخصّصة ويبقى إطار المتصفح الافتراضي؛ و`:has()` في قاعدة واحدة. الصفحات تعمل لكنها أقل راحة. **لم يُجرَّب على جهاز قديم حقيقي**: الفحوص على Chromium حديث مع حذف الواجهات.
- **انقطاع الاتصال بالموقع نفسه** (`ERR_CONNECTION_TIMED_OUT`): الصفحة لا تصل أصلًا فلا يعمل أي سكربت، ولا يعالجه أي مما سبق.

## خط إنتاج البيانات
`data/src/out_g*.json` (تفريغ) → `tools/build.py` (الدفعة 1 → `data/questions.batch1.json` المجمَّدة) → `tools/merge_batch2.py` (الدفعة 2 تُلحَق دون إعادة ترقيم) → `data/verify/result_*.json` → `tools/finalize.py` (+ `overrides.json` و`family_fixes.json`) → `site/data/bank.json`.
ملفات PDF الأصلية والنصوص المستخرجة **لا تُرفع** (انظر `.gitignore` و`DECISIONS.md`).

## تنبيه
الإجابات تحقّق منها آليًا مقابل مراجع ولم يراجعها طبيب. الأسئلة «غير المؤكدة» تظهر بعلامة في المراجعة فقط ولا تدخل الاختبار. لا تعتمد هذا البنك وحده للتحضير.
